# Ejemplos

La colección contiene 87 historias canónicas en Markdown, cada una con una
gráfica SVG, un contrato de datos, un contrato visual y un HTML lineal.

| Casos | Cobertura |
| --- | --- |
| 01-08 | canal de captura, encuesta, leakage, asignación, colas, productividad, dificultad y estacionalidad |
| 09-12 | extrapolación, definición de KPI, umbrales y calidad de taxonomía |
| 13-18 | experimentos, fraude, drift, gobernanza, campañas y decisiones automáticas |
| 19-23 | comunicación con máquinas, etiquetas ambiguas, GenAI, prototipos y agentes con permisos |
| 24-29 | IA, ML, GenAI, RAG, agentes, sesgos, revisión humana y apelación |
| 30-34 | producto de datos, dueño operativo, métrica técnica, costo de error y evaluación por segmento |
| 35-40 | Colab, rutas, VS Code, entornos virtuales, Git y reproducibilidad de datos |
| 41-48 | README, branches, pull requests, asistentes de código, PRD, criterios de aceptación y tareas para agentes |
| 49-54 | programación en Python, estructuras, automatización, funciones, errores y reto Minecraft |
| 55-59 | SQL básico, joins, ventanas, ABT para ML, esquema y contexto |
| 60-62 | lectura de archivos y APIs, pandas esencial y limpieza real |
| 63-67 | conteos y tasas, distribuciones, segmentación, ventanas temporales y valores atípicos |
| 68-72 | selección de gráficas, escalas, color, doble eje y anotaciones útiles |
| 73-77 | sesgo de selección, incertidumbre, pruebas múltiples, causalidad y aleatorización |
| 78-85 | leakage, particiones, desbalance, umbrales, sobreajuste, variables, baselines y explicabilidad |
| 86-87 | monitoreo de modelos, drift y contratos de datos |

No existe carpeta de ejercicios. La única pausa educativa vive dentro de la
historia, donde una persona de la escena hace la pregunta que obliga a mirar la
gráfica.

Los archivos comparten numeración:

- `cases/NN_*.md`
- `data_specs/NN_*.yml`
- `visual_specs/NN_*.yml`
- `html/NN_*.html`

Veredicto editorial esperado: `PASS` solo si la conversación suena real, la
mala lógica da risa y la gráfica enseña qué estaba mal.

La revisión transversal más reciente está documentada en [AUDIT.md](AUDIT.md).
