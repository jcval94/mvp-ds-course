# Instrucciones para agentes

Para crear, ampliar, reescribir o auditar historias en `examples/`, usa siempre
la skill `.codex/skills/create-narrative-case/SKILL.md`.

El Markdown es la fuente canónica. No edites a mano `examples/html/` ni
`../docs/`: genera ambas salidas con las herramientas del repositorio.

Antes de entregar cualquier cambio en historias, ejecuta las validaciones de
estructura, lenguaje, HTML, sitio y pruebas indicadas en la skill. Un caso no
está terminado si repite texto de plantilla, si su diálogo suena a manual o si
la gráfica no cambia una decisión concreta.
