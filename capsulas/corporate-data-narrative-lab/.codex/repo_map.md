# Repo Map

## Raíz del laboratorio

- `ABSURD_OFFICE_COMEDY_DATA_STANDARD.md`: único estándar narrativo.
- `DATA_SCIENCE_CURRICULUM.md`: conceptos y técnica mínima.
- `NARRATIVE_PRINCIPLES.md`, `HUMOR_GUIDE.md`: escritura y ritmo.
- `DATA_VISUAL_EVIDENCE_GUIDE.md`: gráfica central.
- `CASE_RUBRIC.md`, `CODEX_WORKFLOW.md`: revisión y proceso.

## Raíz del repo

- `../docs/`: sitio público regenerado para GitHub Pages.
- `../README.md`: entrada breve del repositorio y cómo publicar Pages.

## `.codex/`

Skills locales para concepto, conflicto, evidencia, escritura, humor,
aprendizaje, render, calidad y publicación de GitHub Pages.

## `templates/` y `prompts/`

Contratos cortos y solicitudes reutilizables.

## `examples/`

Colección de casos con Markdown canónico, data specs, visual specs y HTML lineal.

## `tools/`

Renderer Markdown a HTML, generador de GitHub Pages y validadores de historias,
HTML y sitio.
