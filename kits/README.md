# kits/

Notebooks de Google Colab para alumnos que todavía no programan: ejecutar, mover
controles, observar y decidir. Uno por misión: `kits/<NN-caso>/kit.ipynb`.

Reglas: cero código por escribir, una decisión al final, ejecución completa en
menos de 3 minutos en Colab gratuito, datos por URL fijada a un release.

Los notebooks se guardan **sin outputs** en Git (los outputs son regenerables).
El arnés de ejecución llega en F2 junto con el primer kit.
